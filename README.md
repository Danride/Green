# Зелёный удел 4.0 — стратегия 2.5D

Проект для браузера / VK Mini Apps на Three.js. Разработку можно вести без npm и сборщика.

## Новое в версии 4.0

- Случайная карта размером **128×128 клеток** (раньше 22×22): площадь увеличена более чем в 33 раза.
- **В начале нет ни одной постройки.** На карте уже есть процедурно сгенерированные деревья и каменные залежи; центр оставлен свободным для начала поселения.
- Новый ресурс **камень**: житель добывает его, несёт на каменоломню, и только после доставки начисляется +5 камня.
- Стартовые ресурсы: 200 древесины и 0 камня. Дом стоит 25 древесины, лесопилка 60, каменоломня 70. Дорога стоит 3 древесины + 1 камень.
- Зеленые треугольные элементы травы удалены; оставлены цветовые вариации зелёной поверхности и натуральные серые камни.
- Более яркие цвета, стандартное sRGB без тонмаппинга ACES.
- Средняя кнопка мыши предотвращает браузерный автоскролл; камера ограничена границами мира, дальность видимости увеличена.
- Деревья, пни и камни отрисовываются с помощью InstancedMesh. Территория — один меш с цветами вершин. Курсор выбирает клетку пересечением луча с математической плоскостью вместо проверки тысяч треугольников.
- Новое сохранение `green_fief_v4`, старый проект v3 остаётся в сохранениях браузера отдельно.

## Запуск

Из корня проекта в Windows:

```bat
py -m http.server 8000
```

Открыть `http://localhost:8000/`.

Для публикации на GitHub Pages достаточно `main` + `/ (root)`. Three.js по-прежнему загружается через CDN и требует доступа к сети.

## Структура

- `index.html` — интерфейс
- `css/style.css` — стили
- `js/main.js` — загрузка скриптов
- `js/scene.js` — камера/визуал/параметры территории
- `js/world.js` — процедурная генерация, цвет земли, seed
- `js/models.js` — модели и батчевая отрисовка природы/дорог
- `js/buildings.js` — здания и клеточная сетка
- `js/residents.js` — добыча дерева и камня, доставка
- `js/pathfinding.js` — поиск пути
- `js/cars.js` — машины
- `js/ui.js` — интерфейс
- `js/input.js` — курсор, мышь, касания
- `js/save.js` — сохранения
- `js/startup.js` — загрузка моделей и основной игровой цикл
- `assets/models/` — GLTF из Blockbench
- `tests/` — проверки

## Проверка

В среде, где установлен Node.js (только для тестов, игре он не нужен):

```bat
node tests/check.mjs
node tests/traffic-check.mjs
```
